# Newsynk policy and contact pages

This repository hosts two static HTML pages for the Newsynk Android app:

- `index.html` - privacy policy
- `contact.html` - contact information

These pages have no build process or server-side code. Open either file in a browser for a local preview. GitHub Pages can serve the repository directly from its configured branch.

For the application source and its setup instructions, see [Newsynk](https://github.com/not-a-hack-er/Newsynk).

Policy text should be reviewed whenever the app's data collection, providers, retention, or contact details change. This README describes the site; it is not a substitute for a legal review of the policy itself.
